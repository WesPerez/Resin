# Resin 原生任务目录

`project.json` 发布到 `/opt/resin-operations/operations/`，仅供 `/schedule` 展示应用内任务的
用途和管理入口。它不包含脚本、调度器或凭据，也不启动额外常驻服务。

订阅更新、GeoIP、节点淘汰和指标采样继续由 Resin 原有生命周期管理。出口恢复直接复用
路由服务、租约 CAS 和恢复预算；开关、每平台上限、冷却及运行计数在系统配置页维护。
详见 [原生恢复边界](../docs/automatic-recovery.zh-CN.md)。

跨应用代理池发布、Xray/客户端拨测、Docker 蓝绿切换及 NAT 恢复需要独立的宿主权限，
由 `WesPerez/server-scheduled-tasks` 中的 `tasks/` 唯一维护；本仓库不再保留第二份宿主执行器。
应用的 Go 进程不需要读取其他应用数据库，也不需要 Docker 或 iptables 权限。

部署时先通过应用 CI、镜像 SHA/digest 及蓝绿验收，再更新这两份目录说明。宿主执行入口和
systemd 来源的迁移由中央仓库独立验收；旧脚本只有在所有引用退出后才能回收，不能因更新
本元数据就重启代理连接或删除生产状态。

新增业务后台任务使用应用内部独立模块，复用配置、取消、日志和状态页面，并在此登记入口；
不要为统一展示新增第二套执行计划。
