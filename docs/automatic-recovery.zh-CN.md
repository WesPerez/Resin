# 原生出口恢复

拨号失败在向客户端确认隧道成功前，最多重选两个节点；已建立隧道中的业务内容不重放。取消、客户端写入失败和证书错误不当作节点失败。

已认证客户端可读取或分配普通账号租约，并报告目标传输失败。报告保留观测节点与分配版本的并发比较，旧失败不会修改新租约；现有连接继续完成。自动恢复开关保留。

账号和平台的固定次数、30秒间隔、15分钟三次/一小时暂停等配额已退役。目标失败记录只用于优先避开近期失败出口；没有替代时仍可使用当前健康节点，不以冷却状态阻断请求。

外部 `preferred_candidates`、`preferred_node_hash` 和旧 IP 观察是选择提示。空、重复、过期、缺失或失效提示不会关闭正常平台池。服务仍从当前健康、属于该平台的节点中选择。内部已经拨号的候选提交独自校验实际节点与连接，失败重试不会凭空提交未拨号的第四个节点。

旧代理用户名 `Platform.Account~r1~...` 按 `Platform.Account` 正常路由，附加字段不再锁定节点、IP、分配版本或使用期限。响应兼容字段继续返回，新的下游无需生成该后缀。
